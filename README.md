# WinRE Driver Tool v1.0.0
View/add/remove WinRE drivers.

## Notes
- This is not the same thing as https://github.com/YonatanReuvenIsraeli/Windows-PE-RE-Driver-Loader as that supports WinPE and WinRE and the loaded drivers only last until reboot while this only supports WinRE and changes are persist after reboot.
- This batch file may clear your auto-mount points.
